Tentang Saya

Saya merupakan mahasiswa Sarjana Terapan (D4) Program Studi Sistem Informasi Kota Cerdas di Politeknik Negeri Indramayu dengan minat pada pengembangan aplikasi berbasis web, desain UI/UX, dan analisis data.

Saya memiliki pengalaman mengembangkan aplikasi web dan mobile melalui berbagai proyek akademik, yang mencakup perancangan antarmuka pengguna, pengelolaan basis data, serta implementasi fitur aplikasi sesuai kebutuhan pengguna.

Selain itu, saya juga memiliki pengalaman dalam pengolahan dan analisis data teks menggunakan Python serta teknik dasar Natural Language Processing (NLP). Saya terbiasa bekerja dalam tim, mudah beradaptasi dengan teknologi baru, dan siap berkontribusi secara aktif dalam program magang maupun posisi entry level di lingkungan profesional.
