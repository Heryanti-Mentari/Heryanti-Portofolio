Keahlian & Teknologi

Pengembangan Web

HTML, CSS, JavaScript, dan Bootstrap untuk membangun antarmuka web responsif. PHP dan Laravel (dasar) digunakan dalam proyek akademik seperti sistem CRUD, autentikasi sederhana, dan pengelolaan data berbasis MySQL.

Pengembangan Aplikasi Mobile

Flutter (Dart) untuk pembuatan aplikasi mobile sederhana, mencakup pembuatan UI, navigasi antar halaman, serta integrasi data pada proyek pembelajaran.

Desain UI/UX

Perancangan antarmuka menggunakan Figma, meliputi wireframe, prototipe, dan alur pengguna (user flow) sebagai pendukung pengembangan aplikasi web dan mobile.

Basis Data

MySQL untuk pengelolaan basis data relasional pada proyek web, termasuk perancangan tabel, relasi data, dan operasi CRUD.

Data & Kecerdasan Buatan

Python untuk pengolahan data dasar, text processing, dan penerapan Natural Language Processing (NLP) sederhana dalam konteks tugas dan proyek akademik.

Tools & Pendukung

Git & GitHub untuk version control, Visual Studio Code sebagai editor utama, Postman untuk pengujian API, Google Colab untuk eksperimen data, serta Laragon sebagai lingkungan server lokal.

Keterampilan Nonteknis

Kerja sama tim dalam proyek kelompok, manajemen waktu dalam penyelesaian tugas, adaptabilitas terhadap teknologi baru, serta kemampuan pemecahan masalah secara sistematis.
